# tools/

أدوات تشغيل مساعدة لنشر ECO SAFE CRM (profile `ecosafe`) على ويندوز — ليست جزءاً من الخادم.

| الملف | الغرض |
|---|---|
| `daily_batch_test.py` | يرسل دفعة أسئلة يومية للخادم ويحفظ النتائج في `daily_results_latest.json` و`daily_progress.json` (غير مرفوعين) |
| `daily_auto_run.ps1` | مهمة يومية مجدولة: تشغّل الاختبار اليومي ثم تستدعي وكيلاً آلياً لإصلاح الإخفاقات. اضبط `AGENT_EXE` و`AGENT_ARGS` قبل الجدولة |
| `chat_desktop.pyw` · `تشغيل الشات.bat` | واجهة سطح مكتب بسيطة تتصل بالخادم المحلي (المنفذ 8002) |
